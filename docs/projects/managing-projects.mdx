# Creating & Managing Projects

A **project** in frndOS is the home for one piece of work: usually a client pitch or campaign. It holds the pitches, chats, files, campaigns and people for that work. Each project opens as a [project room](./project-rooms).

> **Studio projects are gone.** frndOS used to have separate Studio projects, folders that every KV had to live in, with their own brief and Brand IQ overrides. They've been removed from the app. Your KVs are now in **Files**, and a KV no longer needs a project before you generate it. Nothing was deleted: files that were in a Studio project simply show no project.

## Where to Find Projects

* **From Home** — the **Projects** section in the sidebar lists recent projects; **See all** opens the Projects page
* **For one brand** — the Projects page's brand filter narrows the list to that brand

The Projects page has:

* **Search projects**
* Status tabs: **All**, **Ongoing**, **Drafts**, **Finished**
* A brand filter (**All brands**) and a type filter (**All types**, or one or more types such as **Pitch**)
* A sort menu: **Recent activity**, **Name A→Z**, **Created**, **Deadline**
* A **Grid** or **List** layout

### Needs you

Projects that need your attention are grouped at the top under **Needs you**, with the rest under **Active**. Each card in **Needs you** says why: **Off track**, **At risk**, or quiet for a while (for example **Quiet 3 wk**). Drafts never need you.

Each card shows the project's cover (its newest deck or key visual), its brand and current step, its status, what's next, its members, and how much is new since you last looked (for example **4 new**). The sidebar's **Projects** list shows the same new count.

> **Heads-up:** the Projects page is part of [Pitch](../early-access/pitch), a Labs feature. If you don't see Projects, Pitch isn't on for your workspace yet.

## Starting a Project

Click **New project** on the Projects page. First pick the project's type:

| Type | Stages |
|---|---|
| **Pitch** | Brief → Strategy → Concept → Pitch → Won / Lost |
| **Campaign** | Plan → Produce → Live → Report → Done |
| **Always-on social** | Plan → Create → Approve → Scheduled → Report |
| **Design job** | Brief → Draft → Review → Final → Delivered |
| **General** | To do → Doing → Done |

A **Pitch** continues with the pitch form: a name, who it's for, an optional deadline, and a brief. See [Creating a Pitch](../early-access/pitch#creating-a-pitch). Every other type only needs a name, a brand and an optional due date.

You can change the type and stage later from the room's header (see [The Room Header](./project-rooms#the-room-header)).

## Filing Work Into a Project

Work lands in a project from inside its room: the room's **New** menu creates decks, canvases, resizes, campaign reports, uploads, tasks and meetings straight into it. While a room is open, the sidebar's **Create** files into it too. From Files, **Move to…** files a file into a project. See [Project Rooms](./project-rooms).

## FAQ

**Q: Do I need a project before making a KV?**
No. Start a KV from the create menu or from Files. It appears in the brand's Files straight away.

**Q: Where did my Studio project's KVs go?**
They're in the brand's **Files**, listed with no project. Use **Move to…** in Files if you want them in a project room.

**Q: What happened to project briefs and Brand IQ overrides?**
They belonged to Studio projects and went with them. The KV Generator now works from the brand's Brand IQ and what you tell it in chat.
