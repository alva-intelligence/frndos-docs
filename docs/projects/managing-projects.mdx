# Creating & Managing Projects

A **project** in frndOS is the home for one piece of work: usually a client pitch or campaign. It holds the pitches, chats, files, campaigns and people for that work. Each project opens as a [project room](./project-rooms).

> **Studio projects are gone.** frndOS used to have separate Studio projects, folders that every KV had to live in, with their own brief and Brand IQ overrides. They've been removed from the app. Your KVs are now in **Files**, and a KV no longer needs a project before you generate it. Nothing was deleted: files that were in a Studio project simply show no project.

## Where to Find Projects

* **From Home** — the **Projects** section in the sidebar lists recent projects; **See all** opens the Projects page
* **Inside a brand** — the brand sidebar's **Projects** section lists that brand's projects

The Projects page has status chips with counts, a sort menu (**Recent activity**, **Name**, **Created**), a brand filter, and a grid or activity view.

> **Heads-up:** the Projects page is part of [Pitch](../early-access/pitch), a Labs feature. If you don't see Projects, Pitch isn't on for your workspace yet.

## Starting a Project

Click **New project** on the Projects page. The same dialog creates a pitch: you give it a name, who it's for, an optional deadline, and a brief. See [Creating a Pitch](../early-access/pitch#creating-a-pitch).

## Filing Work Into a Project

Work lands in a project from inside its room: chats started there, files made for it, and campaigns linked to it. From Files, **Move to…** files a file into a project. See [Project Rooms](./project-rooms).

## FAQ

**Q: Do I need a project before making a KV?**
No. Start a KV from the create menu or from Files. It appears in the brand's Files straight away.

**Q: Where did my Studio project's KVs go?**
They're in the brand's **Files**, listed with no project. Use **Move to…** in Files if you want them in a project room.

**Q: What happened to project briefs and Brand IQ overrides?**
They belonged to Studio projects and went with them. The KV Generator now works from the brand's Brand IQ and what you tell it in chat.
