# Settings & Administration Overview

**Workspace Settings** is the admin control center for your workspace — where owners and admins manage who's on the team, how credits are spent, billing, and which frndOS capabilities are turned on.

Most of these pages are **admin-only** and apply to the **whole workspace**, so a change here affects every member.

## What's in Workspace Settings

The sidebar groups them into sections — **Workspace**, **Customizations**, **Plans**, **You**, and **Labs**:

| Section | Area | What it's for | Guide |
| --- | ------------------ | ------------------------------------------ | ---------------------------- |
| **Workspace** | **General** | Basic workspace details | _Guide coming_ |
| | **People** | Invite members, manage roles and access | See [Workspace & Members](../workspace/inviting-team-members) |
| | **Permission Role** | Define what each role can reach per brand | _Guide coming_ |
| **Customizations** | **Insights Tabs** | Rename and show/hide Insights tabs across the workspace | [Customizing Insights Tabs](./insights-tabs) |
| | **Chat Tools** | Set the default AskFRND tool set for the workspace | [Setting the Workspace AskFRND Tools](./askfrnd-tools) |
| | **Plugins** | Connect an account once for the whole workspace, so members and agents don't each connect their own | [Shared Connections](./shared-connections) |
| **Plans** | **Credit Usage** | Track and allocate credits, buy Extra Credit | See [Managing Workspace Credits](../workspace/managing-credits) |
| | **Billing** | Manage your plan and view invoices | _Guide coming_ |
| **You** | **Notifications** | How much you hear, and where | [Notification Settings](./notifications) |
| | **Privacy** | Export your data or request account deletion | [Your Data Rights](./data-privacy) |
| **Labs** | **Experimental** | Opt the workspace into beta features | [Turning On Experimental Features](./experimental-features) |

> **Renamed:** the workspace tool baseline is listed as **Chat Tools** in the sidebar. It's the same page the [AskFRND Tools guide](./askfrnd-tools) covers.

> **Brand Settings mirrors this.** A brand's own settings carry a **Customizations** section too — with its own **Insights Tabs** and **Plugins**, scoped to that brand.

> **Agents and Workflows moved out of Labs.** They used to sit under Settings → Labs with a beta badge; they're primary navigation now — **myFRND** and **Workflows** in the sidebar. Their links are unchanged.

> More Settings guides are being written. Check the [What's New](/blog) section for updates.

## Where to Find Workspace Settings

1. Log in to **frndOS**
2. Open **Workspace Settings** from the workspace menu
3. Pick the area you need from the settings sidebar — for example, **Chat Tools** under **Customizations**, or **Experimental** under **Labs**

> **Why it's admin-only:** Most settings apply to the entire workspace, so they're gated to owners and admins. If you don't see a page, you likely don't have the permission — or you're in a Personal workspace.

## Admin-Only & Team-Only

Workspace Settings is built for **team workspaces** and **admins**:

- Most pages need the **workspace settings** (or related) permission. Members without it don't see them, and the server enforces the same rule.
- These pages aren't available in a **Personal** workspace.
- Changes are **workspace-wide** — they affect every member, not just you.

## FAQ

**Q: I don't see a settings page (or the whole Settings area).**
Most settings are admin-only and team-only. If you're not an owner/admin, or you're in a Personal workspace, the page won't appear. Ask a workspace admin.

**Q: Do changes here affect my whole team?**
Yes — Workspace Settings applies to the entire workspace, so a change affects every member.

**Q: Where do I manage credits and buy more?**
Under **Credit Usage** (and **Billing** for invoices). See [Managing Workspace Credits](../workspace/managing-credits).

**Q: I can't find AskFRND Tools in the sidebar.**
It's listed as **Chat Tools**, under **Customizations**.

**Q: Agents and Workflows used to be in Settings → Labs.**
They're primary navigation now — **myFRND** and **Workflows** in the sidebar. The routes didn't change.

**Q: I don't see a Dashboard option in Insights.**
Custom dashboards are rolled out to eligible workspaces only. If the entry isn't there, it isn't enabled for you — and a pasted dashboard link won't resolve either.
