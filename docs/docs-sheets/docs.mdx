# Docs

A **Doc** is a document you write inside frndOS, together with your team and with Ask FRND. You can start from a template, type, and ask frnd to draft or change parts of it. Everything frnd changes can be undone.

## Before You Start

1. ✅ Docs is switched on for your workspace. The create menu shows **Doc** when it is.
2. ✅ You can see Files. Docs live there with your other files.
3. ✅ To edit you need edit access to the doc. With **Can comment** or **Can view** access you can read, and comment where allowed.

## Creating a Doc

Open the create menu (**New** or **+**) and choose **Doc**. If your role needs a brand for it, pick one first. frndOS creates an untitled doc and opens it with the chat beside it. If creating fails, the page says **The doc couldn't be created. Please try again.** with **Try again**.

A doc belongs to a brand when you create it from a brand, and otherwise to the workspace. It appears in **Files** under **Docs**. See [Files](../library/overview).

## Starting Points

In an empty doc, a **Start with** list under the first line offers templates:

| Template | What it lays out |
|---|---|
| **Blank** | Just start typing |
| **Article** | Intro, three points and a conclusion |
| **4C Research** | Company, Category, Consumer, Culture, plus a Readout and Sources |
| **Brief** | Objective, audience, message, deliverables |
| **Proposal** | Client proposal: situation, objective, approach, scope, timeline, investment, next steps |

Pick one and the doc fills with its sections. Each template has a starter for frnd too, such as **Draft this article about…**, **Research a brand for this 4C…**, **Write this brief for…** or **Write this proposal for…**. The list disappears as soon as there is anything in the body.

## Writing

The title sits at the top. The doc saves as you type, and other people on the doc appear as avatars in the header. Their cursors move live.

### The slash menu

Type **/** on an empty line to insert a block. Keep typing to filter, use the arrow keys, and press **Enter** or **Tab** to insert. **Esc** closes it.

| Block | What it is |
|---|---|
| **Text** | Plain paragraph |
| **Heading 1**, **Heading 2**, **Heading 3** | Large, medium and small headings |
| **Bullet list**, **Numbered list**, **To-do list** | Lists. To-do items have checkboxes |
| **Table** | Rows and columns |
| **Callout** | Make a point stand out |
| **Quote** | A quotation |
| **Code** | A block of code |
| **Divider** | A line between sections |
| **Image** | From a link. Paste an address that starts with `https://` |
| **Chart** | A figure from numbers you can edit |
| **Stat row** | Two to four big numbers |
| **Personas** | Audience cards with jobs and needs |
| **Competitor scan** | Competitors side by side |

### Formatting a selection

Select text to open a small toolbar with **Bold**, **Italic**, **Strikethrough**, **Link**, the three heading levels, **Comment** and **Ask frnd**. For a link, paste the address and click **Apply**, or **Remove** to take it off.

### The block handle

Point at a block to see its handle at the left. Its menu lets you change the block into another kind (**Turn into**), add a block under it (**Insert below**), **Copy** the block, **Comment** on its text, and **Delete** it.

## Cover

You can add a cover image to a doc. Choose **Add cover**, then **Upload image** or **Generate in Studio** (_Make a new one in Studio_). With a cover in place, **Change cover** lets you swap it and **Remove cover** takes it off. Images you add as blocks can also be opened in Studio.

## Ask frnd

Click **Ask frnd** in the header (tooltip **Show Ask frnd**) to open the chat beside the doc. A doc keeps **one chat thread per person**, so there is no **New chat** or **History** here, and it only docks beside the doc.

On an empty doc it says: _Pick a starting point and tell me what it's about, or just say what to write. Every change can be undone._ On a doc with content: _Tell me what to change in_ the doc's title, _Select text first to point me at a part. Every change can be undone._

Starters: **Make the intro shorter**, **Add a short summary at the top**, and **Which claims have no source?** The chat chips show the doc's name, and the text you have selected, so frnd knows which part you mean.

While frnd writes, a pill in the header reads **frnd is writing**, and the chat shows progress such as **Writing** with the section, and how many sections are done. You can stop it. A run that doesn't finish is marked **Writing stopped** or **Writing failed**.

### Suggestions or direct edits

The header has a switch, **Suggest frnd's edits**. It only shows when you can edit.

* **On:** frnd's changes arrive as suggestions you **accept or reject**.
* **Off:** frnd edits the doc directly, and you can **Undo**.

Its tooltip says which applies: _Others can open this doc: frnd's edits come as suggestions to accept or reject_ when the doc is shared, and _Only you can open this doc: frnd edits directly, with Undo_ when it isn't. Tabs with suggestions waiting show a count such as **2 suggestions to review**.

## Tabs

A doc can have **tabs**, shown in a strip at the top. Each tab has actions: **Rename**, **Move left**, **Move right** and **Delete tab**. Use the arrow keys, **Home** and **End** to move between tabs.

## Comments

Select text and choose **Comment**, or write on the doc as a whole (**Comment on this doc…**). With nothing yet, the panel says: _No comments yet. Select text and pick Comment, or write one below._

* **Resolve** a comment when it is settled.
* **Attach to a sentence** ties a general comment to text you select first. If you haven't selected any, it asks you to **Select a sentence first**.
* A comment whose text was deleted is marked **Detached**.

Mentions, replies and reactions work as in [Collaborating on Insights](../insights/collaborating-on-insights#comments).

## Status

The status pill next to the title reads **Draft**, **In review** or **Approved**. Click it to change it. It is a marker for your team and it never blocks publishing.

## Version History

Click **Version history** (clock icon) to see earlier versions of the doc: who changed it, a summary, and when. You can restore a version. The doc becomes what it was then, and **the newer version stays in history**. You can also **Undo** a change frnd made. If restoring fails, it says **Couldn't restore this version. Try again.**

## Sharing

Click **Share** to open **Share** followed by the doc's name. You can **Add people by name** and give each a role:

| Role | What they can do |
|---|---|
| **Can edit** | Edit the doc |
| **Can comment** | Read and comment |
| **Can view** | Read only |
| **No access** | Remove their access |

The dialog also sets the role for the brand's team (a doc with a brand can be opened by everyone who can open the brand's files, or only by its creator, the people invited and workspace admins). If it fails, a notice says **Couldn't change sharing**.

## Present and Export

The menu beside **Share** (**Doc options**) has:

* **Present** shows the doc alone, in browser full screen.
* **Export as Markdown**, **Export as PDF** and **Export as Word (.docx)**. A notice reads **Word file downloaded**, **PDF downloaded** or **Markdown downloaded**. If it fails: **Couldn't export the doc**.

## FAQ

**Q: Do frnd's edits overwrite my work?**
No. Turn on **Suggest frnd's edits** to review each change, or leave it off and use **Undo**. **Version history** keeps earlier versions either way.

**Q: Can several people edit at once?**
Yes. Everyone's cursor appears live, and changes sync as you type.

**Q: I can't type in the doc.**
You probably have **Can comment** or **Can view** access. A short note in the header says why. Ask an editor for **Can edit**.

**Q: Where is my doc?**
In **Files**, under **Docs**.

**Q: Does it cost credits?**
Writing with frnd runs on your workspace's AI credit, the same as other AskFRND work. See [Managing Workspace Credits](../workspace/managing-credits).
