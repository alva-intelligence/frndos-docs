# Brand Deck Templates

A **deck template** is a starting point that already carries your brand's look. Instead of building a deck and then fixing its colours and fonts, your team picks the template and the deck is on brand from the first slide.

Templates are built from your brand's own [Brand Identity](./brand-identity) — the colours and fonts you set once are the same ones the template uses.

## Before You Start

1. ✅ **Brand Identity set up** — at minimum a colour palette; see [Brand Identity](./brand-identity)
2. ✅ **Access to the brand's Brand IQ** — see [Brand IQ](./brand-iq)

> **Heads-up:** without a colour palette you can't create a brand template. This is deliberate — a template composed from nothing would ship in frndOS's default blue while claiming to be yours.

## Where Templates Live

Inside a brand: **Brand IQ → Templates**.

The tab describes itself as _"Reusable deck templates that keep this brand's decks on brand."_ Every template the brand has appears here, including drafts you haven't published yet.

If there are none: **No templates yet** — _"Create one to keep your team on brand."_

## Creating a Brand Template

1. Click **New template**
2. The **Start with your brand** chooser opens — _"Pick an accent and a font pairing — every layout below updates instantly."_
3. Pick an **Accent** from the swatch row — these are your brand's actual colours
4. Pick a **Fonts** pairing
5. Watch the layouts below re-render in that combination
6. Click **Create template**

> **Tip:** the preview is live and instant. Every accent and font you click recomposes the whole set of layouts immediately, so try a few combinations before committing.

### If Brand Identity isn't set up

If the brand has no colour palette, the chooser shows **Set up Brand Identity first** instead:

> _"A brand template is derived from this brand's colours and fonts. Add them and come back."_

Click **Go to Brand Identity** to set it up, then come back — see [Brand Identity](./brand-identity).

## Using a Template

Once created, the template appears wherever a new deck can be started:

| Where | How |
|---|---|
| **Create menu → Presentation Deck** | The **+** in the sidebar footer, then pick your template |
| **Library → New file → Deck** | The template grid in the **New deck** chooser |
| **Inside a deck** | **Add slide → Templates** to bring template slides into a deck you're already in |

Picking it creates a deck already carrying your brand's colours, fonts, and layouts — see [Decks Overview](../decks/overview).

> **Note:** the consumer-facing galleries only show **published** templates. Drafts are visible in Brand IQ → Templates so you can finish them first.

## Saving an Existing Deck as a Template

Made a deck whose layout you want to reuse? In the deck editor: **Deck menu → Save as template**. See [Decks Overview](../decks/overview).

## FAQ

**Q: Why can't I create a template?**
The brand needs a colour palette in Brand Identity first. Templates are derived from it — see [Brand Identity](./brand-identity).

**Q: Does picking an accent change my brand's colours?**
No. The chooser only **reads** your Brand Identity. Your accent and font choice styles that one template; it never rewrites the brand's own settings.

**Q: Where do the accent swatches come from?**
Your brand's palette. They're one of the few places in frndOS that shows real brand hex values rather than interface colours — the row exists precisely to show your actual colours.

**Q: What's the difference between a template and just changing a deck's theme?**
A template carries layouts and slides as well as the colour and font kit, so a new deck starts with structure, not just styling.

**Q: My template doesn't appear when creating a deck.**
Check it's published. Brand IQ → Templates shows drafts too; the create-a-deck galleries only show published ones.

**Q: Can each brand have its own templates?**
Yes. Templates belong to the brand whose Brand IQ you created them in — see [Managing Multiple Brands](./multiple-brands).
