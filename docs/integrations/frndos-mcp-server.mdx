# Connecting Your AI App — the frndOS MCP Server

**The frndOS MCP server hands frndOS's tools to the AI apps you already use.** Instead of coming to frndOS to look up a brand, your AI app asks frndOS directly — and anything it creates still lands back in frndOS.

The connect dialog puts it as: *"Use frndOS inside your AI — frndOS MCP · every AskFRND tool, one server URL."*

> **Which direction is this?** Plugins and MCP servers in [myFRND](../getting-started/myfrnd) bring outside tools **into** frndOS. This points the other way: it takes frndOS **out** to your AI app. Same workspace, same billing, same permissions.

## Before You Start

1. ✅ **A frndOS account that belongs to at least one workspace** — the server only ever exposes workspaces you're a member of
2. ✅ **An AI app that supports remote (OAuth) MCP servers** — see the list below
3. ✅ **Nothing to install in frndOS.** There's no toggle to flip; you only need the server URL

## The Server URL

```
https://api.frndos.com/mcp
```

You never have to type it. Every entry point below shows the URL with a **Copy** button.

> **If Copy is blocked by your browser:** the dialog selects the URL for you and says *"Copy blocked by the browser — the URL is selected, press ⌘C/Ctrl+C."*

## Where to Find It in frndOS

| Where                        | What you see                                                                                                 |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **AskFRND composer**         | An aqua **frndOS MCP** pill in the toolbar under the message box. Tooltip: *"Connect your AI app to frndOS"* |
| **Chat Settings quick menu** | A **frndOS MCP** item at the bottom of the menu (the sliders button beside the composer)                     |
| **myFRND → Plugins**         | A band at the bottom of the tab, headed **Take frndOS with you**                                             |
| **myFRND → Discover**        | The same band, closing the tab                                                                               |

All of them open the same dialog, or show the same server URL with a copy button.

## Connecting Claude

The four steps below follow the example the connect dialog itself ships: **Add custom connector in Claude**. Claude is the app the dialog illustrates, so this is the path with a picture attached.

Connecting a different app? The frndOS side is identical — see [Connecting Another AI App](#connecting-another-ai-app).

### Step 1 — Copy the Server URL

Open the **frndOS MCP** dialog from any entry point above and click **Copy**. The dialog describes this as *"Your frndOS MCP server address, right above."*

### Step 2 — Add the Server as a Custom Connector in Claude

In Claude, paste the URL as a **remote / OAuth MCP server**. In the dialog's own example, that means opening Claude's connector list, opening the **Add** menu, and choosing **Add custom connector**.

The frndOS server needs no API key or secret alongside the URL.

![Claude's connector list with the Add menu open — choose 'Add custom connector'](/img/connect-claude-example.png)

The dialog labels this shot *"Example: Add custom connector in Claude. Your app's MCP dialog will look similar."*

### Step 3 — Sign In with frndOS

Your AI app opens a frndOS sign-in: *"Your usual frndOS login, scoped to your workspace. Approve once, revoke anytime."*

1. If you're already signed in to frndOS, you go straight to the approval screen.
2. If you're not, frndOS sends you through the normal login page first and then continues automatically. A short interstitial reads **"Connecting your AI app to frndOS…"**.

#### The approval screen

The screen is headed **Connect with frndOS**, with the line *"Grant \[your app] access to frndOS through the MCP server."* It shows three things:

| Block                                                         | What it tells you                                                                                    |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **Your account**                                              | The name and email the connection will act as                                                        |
| **"Workspaces and brands \[app] can access on your behalf:"** | Every workspace you belong to, each with its brands listed underneath                                |
| **"Through the MCP server, \[app] will be able to:"**         | A plain-language capability list — see [What the frndOS MCP Server Can Do](./what-frndos-mcp-can-do) |

Below that, a warning block: **"⚠ Authorization responses will be sent to:"** followed by the app's redirect address.

> **Read that warning.** Any AI app can register itself with any name it likes. The redirect address is the honest signal — if it isn't the app you think you're connecting, click **Cancel**.

Choose **Continue** to approve, or **Cancel** to refuse.

If you don't belong to a workspace yet, the access box reads **"You don't belong to any workspace yet."** — join or create one first, see [Joining or Creating a Workspace](../getting-started/joining-or-creating-workspace).

### Step 4 — Start Asking

*"Every AskFRND tool lights up inside your AI app."*

One rule to know: **every call is scoped to a workspace.** Your AI app has to pick one before it can do anything else — the server tells it to list your workspaces first. If a tool comes back with *"workspace\_id is required. Call list\_workspaces to see the workspaces you belong to."*, just tell your app which workspace you mean.

Brand-scoped requests need a brand as well; the app looks those up from the brand directory of the workspace it's in.

## Connecting Another AI App

**Works with:** claude.ai, ChatGPT, Claude Desktop, Cursor, Gemini, **and any MCP client**. The myFRND band lists **Claude**, **ChatGPT**, **Cursor**, and **Claude Code**.

Only **Step 2** changes between apps — the slot goes by different names (*custom connector*, *remote MCP server*, *add server by URL*), and where it lives is that app's own UI. Steps 1, 3 and 4 are the frndOS side and are the same everywhere:

1. Copy the server URL from the **frndOS MCP** dialog — see [Step 1](#step-1--copy-the-server-url)
2. Paste it into your app's remote / OAuth MCP server slot, with no API key or secret
3. Sign in and approve — see [Step 3](#step-3--sign-in-with-frndos)
4. Pick a workspace and start asking — see [Step 4](#step-4--start-asking)

Wherever the slot lives in your app, you need exactly two things from frndOS: the **server URL**, and a sign-in when the app asks for it.

## What You'll See When Something Is Blocked

The server refuses in plain sentences rather than error codes:

| Message                                                                                                                        | What it means                                                                                                 |
| ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| *"You do not belong to this workspace. Call list\_workspaces to see valid workspace ids."*                                     | The app aimed at a workspace you're not a member of. Brand ids from other workspaces read as **not found**    |
| *"Your role in this workspace does not allow tool access. Tools require an internal-scope role in an organization workspace."* | Guest / external-scope membership can't use tools                                                             |
| *"This action requires an active subscription plan."*                                                                          | Anything that **creates or changes** something needs an active workspace subscription                         |
| *"Insufficient credits. The workspace (or your allocation in it) has no spendable credits."*                                   | Key Visual generation and workflow runs spend credits — see [Managing Credits](../workspace/managing-credits) |
| *"Tool execution failed unexpectedly. Try again or adjust the arguments."*                                                     | Something broke on the frndOS side; retry or rephrase                                                         |

> **Heads-up:** the connection carries **your** permissions, not extra ones. If you can't see a brand in frndOS, your AI app can't either.

## Limits and Session Length

* **Rate limit:** 60 tool calls per minute, counted per user.
* **Access lasts 24 hours**, then your AI app renews it silently in the background for up to **30 days** without asking you again.
* Reconnecting the same app later usually skips the approval screen, because you already approved it.

## Security

The footer of the connect dialog states it: *"OAuth 2.1 + PKCE — tokens scoped to you, validated against your workspace on every call."*

* Your frndOS password is never given to the AI app. It gets a token, and the token is tied to you.
* Every single call re-checks your workspace membership — approval isn't a permanent free pass to data you later lose access to.
* Connections are only accepted over `https` (a plain `http` callback is rejected unless it's your own machine).

## FAQ

**Q: Do I need to enable anything in frndOS first?**
No. There's no Labs toggle and no admin switch on your side — you only need the server URL and an AI app that can add a remote MCP server.

**Q: Is this the same as adding an MCP server in myFRND?**
No, it's the opposite direction. myFRND → **Plugins** lets frndOS use *other* servers' tools. This lets *other* apps use frndOS's tools. See [myFRND](../getting-started/myfrnd).

**Q: Does work done in my AI app show up in frndOS?**
Yes. A deck, a Key Visual, an agent, a campaign plan — it's created in your frndOS workspace, exactly as if you'd made it in the app.

**Q: Does it cost credits?**
Generating a Key Visual or running a workflow spends credits the same way it does inside frndOS. Reading brand knowledge or insights doesn't.

**Q: Can my teammates use my connection?**
No. Each person connects their own AI app and sees only what their own account can see.

**Q: How do I disconnect an app?**
Remove the frndOS MCP server in the AI app itself, which stops it calling frndOS.

**Q: I got "This authorization link is invalid or incomplete."**
The handoff link was broken or truncated. Close the tab and start the connection again from your AI app.

**Q: I got "Connecting AI apps to frndOS is temporarily disabled."**
The connection bridge is off for the moment. Try again later.
