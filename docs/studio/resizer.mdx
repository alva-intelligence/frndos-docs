# Resizing Visuals for Different Platforms

The **Resizer** lets you take a single visual — generated in KV Generator or uploaded directly — and adapt it across multiple platform sizes and aspect ratios, without redoing the work from scratch.

## When to Use the Resizer

Use the Resizer when:
- Your KV (or any image you have) is **approved** and ready for delivery
- You need to deploy across **multiple platforms** (Instagram, TikTok, banners, etc.)
- You want consistent visual identity across all sizes

Don't use the Resizer for major concept changes — those belong in the [KV Generator](./kv-generator) refine step.

## Before You Start

You need:
- A finalized KV from the KV Generator (in Craft mode) **or** your own image uploaded into Craft mode — see [Creating Your First Key Visual](./kv-generator)
- Knowledge of which platforms/sizes you're targeting

## How to Resize

### Step 1 — Open Resize Mode

Switch to the **Resize** tab in the top nav. The canvas switches to a vertical list view showing your source image and any completed resize tiles below it.

### Step 2 — Select Platforms from the Platform Panel

A **Platform** panel appears on the left side of the canvas. Platforms are grouped into three collapsible sections:

| Group | Default state |
|-------|---------------|
| **Social Media** | Expanded |
| **Print** | Collapsed |
| **Digital** | Collapsed |

Click any platform row to toggle it. Each row shows the platform name and its pixel dimensions. The **Start Resizing** button at the bottom of the panel updates with the count and estimated credit cost as you select:

> `Resize · N selected · ~X credits`

#### Adding a custom size

If the size you need isn't in the list, add it yourself. Below the platform groups, enter a **Width** and a **Height**, then click **Add**.

Both sides must be whole numbers between **64** and **8192**. If one isn't, the panel names the offending axis rather than just refusing:

> **Width must be a whole number between 64 and 8192.**

Adding a size you already have says so too — **1080 × 1350 is already added.**

> **Heads-up:** custom sizes are only available for KVs **composed from layers** — a [PSD import](./kv-generator#import-psd-files) or Magic Layers. For an AI-generated KV the panel says so instead:
>
> _"Custom sizes are only available for KVs composed from layers (PSD import or Magic Layers)."_
>
> The reason is cost and quality: resizing a generated KV goes back through the image model, where an arbitrary size spends credits and degrades at extreme ratios. A layered KV is re-laid out directly, so any size is safe.

### Step 3 — (Optional) Add Resize Instructions

Below the platform list, a **text area** lets you add a prompt that applies to the entire batch:

> **Placeholder:** _Any specific instructions? (Optional)_

Use this to guide the AI on how to handle the adaptation — for example: _"keep the logo in the top-right and preserve all text"_ or _"extend the sky at the top"_. The instruction is sent alongside every platform in this batch. Maximum 1000 characters.

If you leave it empty, the AI adapts freely from the source image.

### Step 4 — Generate

Click **Start Resizing** to kick off the batch. Each selected platform generates independently:

| Row state | What you see |
|-----------|-------------|
| **Queued** | Checkbox checked — will run when you click Start Resizing |
| **In progress** | Spinner + **Cancel** button |
| **Done** | Green check — click the row to jump to that tile on the canvas |
| **Failed** | Red warning icon — click the row to retry immediately; or click **Discard** to remove it |

> **Note:** Resize uses a fixed model — no model picker. Just describe what you want and let the AI handle the adaptation.

When a tile is done, a **download** option appears in its tile toolbar on the canvas so you can export that size individually.

## Refining a Specific Tile (Per-Tile Regenerate)

After a tile is done, you can regenerate it with a new prompt — without touching the other tiles.

1. Hover over a completed tile on the canvas — a toolbar appears with action buttons
2. Click the **Regenerate** button (circular arrows icon, `⟳`) to arm that tile
3. A chip appears in the chat composer showing the platform name, dimensions, and a thumbnail of the current result
4. Type your instruction in the chat input and press **Enter** (or click **Send**)
5. The AI regenerates that tile from the source image, applying your new instruction

To cancel without regenerating: click **✕** on the chip in the chat composer (or the same Regenerate button again — it toggles).

> **Example:** After resizing to Stories 9:16, you notice the product is cropped. Click ⟳ on that tile → type _"ensure the full product is visible, don't crop the packaging"_ → Send.

> **Note:** The chat input in Resize mode does not go to an AI agent — it fires a direct regenerate call on the selected tile. Attachments and model selection are not available in this mode.

## Editing Part of a Tile (Region Edit)

Sometimes a whole regenerate is too blunt — the tile is right except for one thing. **Region edit** lets you draw a box on a tile and prompt an AI edit of just that area.

> **Rolling out gradually:** region editing on Resize tiles is enabled per workspace. If the frame tool isn't offered on a tile, it hasn't reached you yet — see [Turning On Experimental Features](../settings/experimental-features).

### Draw a frame

Pick the **frame** tool and drag a box over the part of the tile you want changed. A pill appears under the frame with two ways forward:

| Choice | What it does |
|---|---|
| **Find objects** | Runs AI detection **inside that frame** and lists what it found, so you can target a real object instead of a rectangle |
| **Edit this area** | Skips detection — the prompt applies to the rectangle exactly as drawn |

> **Detection is never automatic.** It's a paid model call, so drawing a frame stops at this choice rather than spending credits on its own.

### Picking an object

**Find objects** lists what overlaps your frame, **smallest first** — the most specific match leads. Hover a row to outline it on the tile; click to select it. You can pick more than one, and the prompt then covers the group.

If the automatic pass missed what you meant, the list has a search box: _"Not listed? Describe it"_ — type what you're after in your own words and it re-queries the same frame.

Found nothing at all? The frame reports **No object found here**, and your hand-drawn rectangle is still there to use with **Edit this area**.

### Writing the prompt

The popover's placeholder tells you what it's aimed at:

| Situation | Placeholder |
|---|---|
| One detected object | _"What should happen to this?"_ |
| Several objects selected | _"What should happen to these N?"_ |
| A hand-drawn area | _"Add prompt..."_ |

**Enter** saves, **Escape** backs out. The secondary action reads **Cancel** for a detected selection (it steps back to the object outlines) and **Delete** for a hand-drawn box (it removes the frame).

> **Save stages, it doesn't generate.** You can set up several regions first — one send fires them all.

## Editing the Original Row

The **Original** row at the top of the Resize surface isn't just a reference — you can edit it like any tile. Move a logo, fix a caption, adjust a shape, and the change flows down to every tile that hasn't been adjusted on its own.

> **Rolling out gradually:** the editable Original row is enabled per workspace. If your Original row is read-only, it hasn't reached you yet.

A tile you've already adjusted keeps its own version — editing the Original never overwrites per-tile work.

### Push to all tiles

To force every tile back to the Original's layout, click **Push to all tiles** above the rows.

This is destructive, so it asks first. The dialog **Push master to all tiles?** tells you exactly what you're about to lose:

> _"N tile(s) have their own adjustments. They'll be discarded and re-derived from the master. This can't be undone."_

**Cancel** backs out; **Push to all tiles** confirms.

> **Heads-up:** this one genuinely can't be undone. Deleting a single overlay on the Original is an ordinary edit that Cmd+Z restores — clearing every tile's own adjustments in bulk is not.

> **Note:** the button is disabled when no tile has its own adjustments, because there'd be nothing to discard.

## FAQ

**Q: Does Resize Mode just crop, or does it intelligently adapt?**
Resize Mode adapts the visual to the target dimensions — not a simple crop. Important elements stay visible and the composition remains balanced.

**Q: Can I resize an externally-made image?**
Yes. In Craft mode, use **Upload Image** to bring in any image you already have — no generation required. Once uploaded, it behaves like a generated KV, so you can send it straight to Resize Mode.

**Q: What's the difference between the batch instruction and the per-tile regenerate prompt?**
The **batch instruction** (textarea in the Platform panel) applies to all selected platforms when you click Start Resizing — it guides the initial adaptation for the whole batch. The **per-tile prompt** (via the ⟳ button on a done tile) regenerates just one tile with a new instruction, without touching the others. Use the batch instruction when you have a general rule for all sizes; use per-tile when a specific format needs an adjustment.

**Q: Can I customize the resize per platform?**
Yes. Use the per-tile regenerate (⟳ button) to refine any individual tile after the initial batch run. Each tile can be retried with different instructions independently.

**Q: Can I set a fully custom size?**
Yes, for a KV composed from layers (a PSD import or Magic Layers) — enter a **Width** and **Height** in the Platform panel and click **Add**. Both sides must be whole numbers between 64 and 8192. For an AI-generated KV the option isn't offered, because that path re-runs the image model where an arbitrary size costs credits and degrades at extreme ratios.

**Q: Why is the custom size field greyed out?**
The KV you're resizing was generated by AI rather than composed from layers. Import a PSD or use Magic Layers to get a layered KV, and the field becomes available.

**Q: What platforms are supported?**
Common social and ad platform dimensions are pre-configured under Social Media, Print, and Digital groups. Check inside Resize Mode for the current list. Print-specific specifications (e.g., CMYK, print-ready output) are not part of the current social-media-focused resize flow.

**Q: What's the difference between a region edit and regenerating the tile?**
A **regenerate** (⟳) redraws the whole tile from the source with a new instruction. A **region edit** repaints only the area inside the frame you drew and leaves the rest of the tile alone. Use region edit when the tile is nearly right.

**Q: I drew a frame and nothing was detected.**
The frame says **No object found here**. Your rectangle still stands — use **Edit this area** to prompt against the area itself, or try the _"Not listed? Describe it"_ search with your own wording.

**Q: Can I edit several regions in one go?**
Yes. Saving a region prompt stages it; set up as many as you need and one send fires them together.

**Q: Can I download just one resized tile?**
Yes. Once a tile is done, hover over it on the canvas — a download button appears in its toolbar so you can export that size individually. To download all tiles at once, use the **Download All** option in the canvas toolbar.
