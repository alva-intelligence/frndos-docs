# Studio Overview — Your Creative Toolkit

**Studio** is the name for frndOS's creative tools: where you turn ideas into final visual assets, with AI handling the heavy lifting while you stay in creative control.

> **Studio is no longer a sidebar pillar.** The tools are still here; you reach them through the brand's **Files** and the create menu. See [Where to Find the Tools](#where-to-find-the-tools).

## What's in Studio

Studio is a collection of creative tools, all aware of your Brand IQ:

| Tool                  | What It Does                                      | Best For                                    |
| --------------------- | ------------------------------------------------- | ------------------------------------------- |
| **KV Generator**      | Generate Key Visuals from concept to final        | Campaign hero visuals, social posts         |
| — Concept mode        | Explore creative territories with the Conceptor agent | Ideation, divergent exploration         |
| — Craft mode          | Refine one concept into a production-ready KV; create AI variants of any board | Polishing, bounding box edits, variants     |
| — Motion _(Labs)_ | Animate a finished KV on a timeline — layers, keyframes, audio, MP4 export | Social video, animated ads                |
| **Resizer**           | Adapt one visual to multiple platform sizes       | Cross-platform delivery                     |

> More Studio tools are rolling out — including Storyboard, Editorial Planner, and Campaign Creator. Stay tuned via the [What's New](/blog) section.

## Where to Find the Tools

**To start something new:**

* **Key Visual** — the **+** create menu in the sidebar footer, or **New** on the Files page
* **Resize** — **New** on the brand's Files page

**To open something you made:** open the brand, click **Files** in the brand sidebar, and open the KV or resize. Motion projects open from inside their KV.

> **Why select the brand first?** The tools are brand-aware: they pull from whichever brand is active. Picking the right brand before you start ensures your output inherits the correct Brand IQ.

> **No access?** If your role doesn't include a tool, opening one shows _"You don't have access to this canvas"_. Your files are still in Files.

> **Heads-up:** if a brand's Brand IQ isn't complete, Studio flags it as **Brand IQ Incomplete** (or **Brand IQ — Not configured** when nothing is set) before you generate. See [Brand IQ](../brand-setup/brand-iq).

## The Studio Workflow

Most creative work in Studio follows a consistent flow:

```
1. Brand IQ (set once per brand)
        ↓
2. Create a Project (campaign-level context)
        ↓
3. Generate in KV Generator (Concept → Craft)
        ↓
4. Resize for platforms (on the Craft canvas)
        ↓
5. Animate (Motion, optional)
        ↓
6. Share for review (client links)
```

## Why Studio is Different from Standalone AI Tools

Most standalone AI image tools start from a blank prompt every time. Studio is different:

* **Brand-aware by default** — every generation inherits your Brand IQ
* **Project-scoped** — campaign context (brief, audience, direction) is baked in
* **End-to-end workflow** — concept → refine → resize, all in one platform

This means less prompt engineering, more consistent output, and faster turnaround.

## Who Should Use Studio

Studio is built for the full creative team:

* **Designers & Art Directors** — fast ideation, finalization, and platform adaptation
* **Account Managers & PMs** — explore directions without waiting for design resources
* **Creative Directors** — review concepts and provide direction in real-time
