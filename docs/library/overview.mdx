# Library Overview — Your Team's File Hub

The **Library** is a single place for everything your team has created. Key Visuals, decks, reports, research projects, shared documents, and uploaded files — all in one searchable list, organised by brand, project, or file type.

## What's in the Library

The Library automatically indexes every file your team creates across frndOS tools. When you make a new KV, save a deck, or complete a research project, it appears in the Library without any extra steps.

| File Type (Kind) | Created In |
|-----------------|------------|
| **KV** | Studio — KV Generator |
| **Deck** | Deck Editor |
| **Report** | Insights — Campaigns |
| **Research** | Research tools |
| **Doc** | Dynamic artifact documents |
| **Upload** | Published workflow artifacts |

Each file shows its **title**, **brand**, **project** (if filed under one), **status**, and **last activity** time.

## Accessing the Library

- **From anywhere** — Click **Library** in the sidebar (the bookshelf icon). This shows files from all brands in your workspace.
- **Inside a brand** — Click the brand in the sidebar, then **Library**. This shows only files from that specific brand.

## Searching & Filtering

The Library toolbar gives you several ways to find files:

**Search** — Type a keyword to search across file titles. Results filter as you type (300 ms debounce).

**Filters** — Click each filter trigger to narrow down:

| Filter | What it does |
|--------|-------------|
| **Kind** | Show only KVs, or only Decks, Reports, Research, Docs, or Uploads |
| **Status** | Filter by Draft, In review, Approved, or Archived |
| **Brand** | Scope to one brand. Shows a row of brand chips below the toolbar for quick switching. |
| **Project** | Show files from a specific Studio project |

**Scope** — Toggle between **My files** (only files you created) and **All files** (everyone in the workspace).

**Sort** — Order results by:
- **Recent activity** (default) — Most recently updated first.
- **Name A→Z** — Alphabetical by title.
- **Date created** — Newest first.

**Group by** — Split the list into sections by Kind, Brand, Project, or Status.

**View** — Switch between **Grid** (thumbnail cards) and **List** (compact rows).

> **Tip:** Filters and sort persist during your session but reset on fresh navigation.

## File Actions

Clicking a file card or row opens it in its native editor (KV opens in KV Generator, Deck opens in the Deck Editor, etc.).

**Right-click** (or the row's action menu) gives you:

| Action | What it does |
|--------|-------------|
| **Open** | Opens the file in its tool |
| **Rename** | Edit the file's title |
| **Set status** | Change status: Draft → In review → Approved → Archived |
| **Duplicate** | Create a copy (not available for uploaded files) |
| **Move** | File under a different brand, project, or unfile it |
| **Delete** | Move to Trash |

### Status Lifecycle

Track where each file is in your workflow:

| Status | Meaning |
|--------|---------|
| **Draft** | Work in progress — not yet shared for review. |
| **In review** | Under review by a team member or client. |
| **Approved** | Reviewed and approved. Ready for use. |
| **Archived** | No longer active but kept for reference. |

Use the status dropdown on a file card or select multiple files via bulk bar to set status in one action.

### Bulk Actions

Select multiple files (using the checkbox on each card/row or Shift-click range selection) to perform bulk actions:

- **Set status** — Change all selected files to Draft, In review, Approved, or Archived.
- **Delete** — Move all selected files to Trash.

A floating bulk action bar appears at the bottom of the screen when one or more files are selected, showing the count and available actions.

## Trash

Deleted files go to **Trash** for **30 days** before they are permanently deleted.

In the Trash view:

- **Restore** — Return a trashed file to the Library, exactly as it was.
- **Delete forever** — Permanently remove a file immediately (cannot be undone).
- **Empty Trash** — Permanently delete every item in the Trash.

> **Tip:** If you accidentally delete a file, go to Trash and restore it before the 30-day window expires.

## Creating New Files from the Library

The **New** button in the toolbar offers:

- **KV** — Opens KV Generator to create a new Key Visual.
- **Deck** — Opens a template chooser (start blank or pick a published template).
- **Template** — Creates an editable deck template.

Reports, Research, and Docs are created inside their own tools and appear in the Library automatically.

## FAQ

**Q: Can I file a Library item under a Project?**
Yes. Use the **Move** action to file a Library item under a specific brand and/or project. Unfiled items show a small prompt nudging you to file them.

**Q: Do deleted files count toward my storage?**
No. Once deleted, files are removed from active storage. They remain in Trash for 30 days for recovery before permanent deletion.

**Q: Can I see who created a file?**
Yes. The file card shows the creator's name. Use **My files** toggle to see only your own files.

**Q: Are Research files listed in the Library?**
Yes, research projects (surveys, customer intelligence studies) appear in the Library once created.
