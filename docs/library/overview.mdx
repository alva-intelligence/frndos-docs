# Files — Your Team's File Hub

**Files** is a single place for the files your team has created: canvases (key visuals), resizes, decks, reports, research, shared documents and uploads, in one searchable view. It used to be called the **Library**; old Library links open Files.

## What's in Files

Files are listed automatically as your team creates them across frndOS. Make a KV, save a deck or finish a research study and it appears here without any extra steps.

| Type | Created in |
|-----------------|------------|
| **Canvases** | The KV Generator (key visuals) |
| **Resizes** | The Resizer |
| **Decks** | The deck editor |
| **Reports** | Insights — Campaigns |
| **Research** | Research |
| **Docs** | Documents frnd writes (artifacts) |
| **Uploads** | Files you uploaded |

> **Studio is now in Files.** There's no Studio module any more. KVs and resizes are opened from Files.

## Opening Files

* **From anywhere** — click **Files** in the sidebar. This shows files from every brand you can open.
* **For one brand** — pick the brand under **Brand** in the **Filter** menu.

## What You Can See

Files shows what your access allows. It isn't a list of literally every file in the workspace.

**Inside a brand**, some file types are tied to a pillar or tool, and you only see them if your role grants it for that brand. Key visuals and resizes follow your access to the creative tools, research follows Research, and reports follow Insights. Decks, docs and uploads are always shown.

> **Heads-up:** this is why two people can open the same brand's Files and see different files. If you expect a file type and don't see it, ask a workspace admin about your brand role (see [Inviting Team Members](../workspace/inviting-team-members)).

Brands you have no access to never appear at all.

## Finding a File

The header carries the search, the type chips and the view controls.

* **Search files** — narrows by title as you type
* **Type chips** — **All (n)**, then one chip per type that has files, each with its count
* **Filter** — one menu for **Owner** (**Anyone** / **My files**), **Status** (each with a dot and count), **Unfiled** (files in no brand or project; on the workspace page), and **Brand** (on the workspace page, with **Find a brand** when there are many). It reads **Filter · 2** with two filters on
* **Group by** — **None**, **Type**, **Status**, **Brand** or **Project**. It reads **Group by Status** once grouped
* **Sort** — **Last edited**, **Name** or **Date created**
* **Grid view** / **List view** — thumbnail cards or rows. The list has a status column

**Clear filters** resets them. With nothing matching, the page says **No files match**.

## Opening and Previewing

Clicking a file opens it in its tool **in a new tab**. **Open in this tab** is in the file's **⋯** menu.

**Quick Look** previews a file without opening it: press **Space** on a focused file, or pick **Quick Look** from its menu. Use **←** / **→** to step through files, and **Esc** or **Space** to close. The preview shows its type, brand, last edit and comments.

### Keyboard

Files works like Finder:

| Key | What it does |
|---|---|
| Arrow keys | Move between files |
| **Home** / **End** | First / last file |
| **Enter** | Open (new tab) |
| **⌘/Ctrl + Enter** | Open in this tab |
| **Space** | Quick Look |
| **Delete** / **Backspace** | Move to Trash (asks first) |
| **⌘A** | Select every loaded file |
| **Esc** | Clear the selection |

## File Actions

Each file's **⋯** menu (or right-click) offers:

| Action | What it does |
|--------|-------------|
| **Open** / **Open in this tab** | Opens the file in its tool |
| **Quick Look** | Previews it |
| **Rename** | Edit the file's title |
| **Set status ›** | **Draft**, **In review**, **Approved** or **Archived**, with Undo |
| **Duplicate** | Makes a copy. A canvas copy includes its boards, sizes and motion (_"Uploaded files can't be duplicated"_) |
| **Move to…** | Files it under a brand and/or project, or unfiles it |
| **Move to Trash** | _"It will move to Trash. You can restore it from Trash for 30 days."_ |

### Status

| Status | Meaning |
|--------|---------|
| **Draft** | Work in progress, not yet shared for review |
| **In review** | Under review by a team member or client |
| **Approved** | Reviewed and approved, ready for use |
| **Archived** | No longer active but kept for reference |

A file that isn't a draft shows its status on its card, for example **● In review**.

### Working with Several Files

Select files with the checkbox on a card or row, **⌘-click**, **⇧-click** for a range, or **⌘A**. A bar shows how many are selected, with **Move to…**, **Set status**, **Move to Trash** and **Clear selection**. Every bulk action has an Undo.

## Importing a PowerPoint or PDF

Drop a .pptx or .pdf anywhere on the Files page, or use **New** → **Import PowerPoint or PDF**, to turn it into a deck. One import runs at a time. When it's ready, a toast offers **Open**; the deck is also in the list.

## Creating New Files

**New** in the header opens the create menu: **Canvas**, **Resize**, **Presentation Deck**, **Survey**, **Persona**, **Image Generation**, and **Import PowerPoint or PDF**. Reports are created in Insights and appear here automatically.

## Trash

The Trash button in the header shows how many files are deleted. Deleted files stay in Trash for **30 days**:

* **Restore** returns a file exactly as it was
* **Delete forever** removes it now (can't be undone)
* **Empty Trash** permanently deletes what's in this Trash, after you confirm. On a brand's tab it empties only that brand's Trash (_"Permanently delete 2 files in by.U's Trash."_). On the workspace's Files page it empties the workspace's Trash

## FAQ

**Q: Empty Trash on a brand's tab. Did it delete other brands' files?**
No. A brand's tab empties only that brand's Trash. The confirmation names the brand before anything is deleted.

**Q: Does duplicating a canvas copy everything?**
Yes. The copy includes its boards, sizes and motion.

**Q: Where did the Library go?**
It's called **Files** now. Old Library links open Files.

**Q: Where did Studio go?**
KVs and resizes live in Files now. Start a new one with **New**, or open an existing one from the list.

**Q: Can I file something under a project?**
Yes. **Move to…** files it under a brand and/or project. Use the **Unfiled** filter to find files that aren't in any brand or project.

**Q: A colleague can see a file I can't. Why?**
Inside a brand, key visuals, resizes, research and reports each need the matching access for that brand. See [What You Can See](#what-you-can-see).

**Q: I deleted a file by mistake.**
Open Trash and **Restore** it within 30 days.
