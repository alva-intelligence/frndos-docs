# Scorecard Reports and Rubrics

Once a [Proposal Scorecard](./proposal-scorecard) is scored, you can turn it into a **report** for people outside the scorecard: a written answer with live charts and the pages that back it up. This guide also covers the **rubric**, the standard every scorecard is scored against, and how to set it up.

## Before You Start

1. ✅ **A scored scorecard**, see [Proposal Scorecard](./proposal-scorecard)
2. ✅ **Permission to change this brand's scorecards** to build or share a report
3. ✅ **Workspace or brand settings access** to change a rubric

## Exporting a Scorecard

Click **Export report** on the scorecard's header. You get two choices:

| Choice | What you get |
|---|---|
| **Full report** | _"Built in Ask FRND beside the scorecard: the answer, charts and page evidence. Share, PDF or slides from there."_ |
| **One-page summary** | _"The score, the overview and the top changes on one slide."_ It opens as a deck in a new tab, where you can edit it or download it as PDF or PPTX |

Once a full report exists, the menu also offers **Open the report**.

**Copy link** beside it copies the scorecard's own address, for people in your workspace who can open this brand's research.

## Building the Full Report

Choosing **Full report** opens AskFRND beside the scorecard and starts the build. A card in the chat follows each step: **Story and takeaway**, **Score charts and potential**, **Evidence pages**, then **Decision and next steps**.

When it reads **Your report is ready**, the card offers **Open report**, **PDF** and **Slides**. Steer the next version with the chips (**Shorter**, **For the CMO**, **In Bahasa Indonesia**, **More formal**) or by typing what you want changed.

You can also start from any AskFRND chat. Ask it to build the report for a scorecard and paste the study's link, for example _"Build the report for this scorecard in Bahasa Indonesia"_. A report can only be built once the scorecard is scored.

### What's in the report

The report answers first, then shows the reasoning:

* The answer and the takeaway
* **Where it stands**, with score charts that stay live with the scorecard
* What's working and what's holding it back, with thumbnails of the pages that show it
* The changes to make and what they're worth
* The decision and next steps, then an appendix with the method

Page references open the page of the original file.

For a file scored in parts, there's still **one report per file**. Each part has its own section, and **Across parts** carries the decision. Readiness comes from the weakest part, never a blended number.

> **Scores changed since it was written?** The report's charts stay live, but its words don't rewrite themselves. The **Export report** menu says so, and you can rebuild it from the report.

## Sharing the Report

The report page has three ways out.

### Share link

Click **Share**: _"Anyone with the link can read it — no frndOS account, no source file, no edits. The numbers stay live with the scorecard."_

1. Pick when the link expires (**7 days**, **30 days** or **No expiry**)
2. Click **Create and copy link**

Each live link is listed with **Copy** and a way to revoke it. A report keeps at most three live links; revoke one to make another.

### PDF

Click **PDF** to download the report as a paged PDF.

### Slides

Click **Present as slides** to build a deck from the report in the brand's look. It opens in a new tab, where you can present it or download PDF or PPTX. Once the slides exist, **Rebuild slides** makes them again from the current report.

## Setting the Rubric

The rubric decides what a scorecard looks at and how much each part counts. It's set at two levels:

* **Workspace Settings → Scorecard Rubric** is the standard every brand in the workspace inherits
* **Brand Settings → Scorecard Rubric** holds only what one brand does differently. Anything left alone keeps following the workspace

Each review type (**Proposal**, **Creative material**, **Media plan**) has its own rubric. Pick one from the tabs.

### What you see first

A card sums up the rubric, for example **Using the frndOS default**, how many criteria or dimensions it scores, and its scale. For a proposal: _"Strategy and Ambition each run 0–100."_ For a creative or a media plan, the card lists the frndOS bands: **85+ Ready**, **70–84 Minor revision**, **50–69 Major revision**, **below 50 Rework**.

Below it, **What counts toward the score** shows each part's share.

### Customizing in minutes

Click **Customize for this workspace** (or **Customize for this brand**). Start one of three ways:

| Start | What it does |
|---|---|
| **Import your scorecard** | _"Upload the PDF or DOCX you use today; it's mapped onto the frndOS scale for you to check."_ It shows what mapped and what didn't |
| **What matters most here?** | _"Pick a focus; it sets the shares and switches on the checks that go with it."_ |
| **Adjust weights by hand** | Drag each part's share of the score |

Before you save, a preview shows how your last scorecards would read with the change, for example a score moving up three points into a new band. _"Re-totalled from stored scores · no credits."_

Click **Save for this workspace** (or **Save for this brand**). _"New scorecards use it. Scorecards already run keep the version they used."_

Need more control? **Advanced** opens the full form: criteria, descriptions, band labels and gates for a proposal, or dimensions, descriptions and the full rubric for the other types.

To undo your changes, click **Reset to frndOS** (workspace) or **Reset to workspace** (brand).

### Which review types people can pick

In **Workspace Settings → Scorecard Rubric**, an admin can also choose:

* **Default when the reviewer isn't sure**, the type preselected when a file could be more than one type, or none. People still confirm it with the brief
* **Offer creative material reviews** / **Offer media plan reviews**. Turning one off hides that type when people start a scorecard. _"A file detected as this type still shows it, so the review can be confirmed."_

## FAQ

**Q: Who can read a report share link?**
Anyone who has the link. They need no frndOS account and see no source file. Revoke the link to stop access.

**Q: Will the report change if someone overrides a score?**
The charts and numbers stay live with the scorecard. The written parts don't change by themselves; rebuild the report to rewrite them.

**Q: Can AskFRND set up the rubric for me?**
No. AskFRND can run a scorecard and build its report, but the rubric is set in **Scorecard Rubric** settings. To start from the scorecard you already use, pick **Import your scorecard**.

**Q: Does previewing a rubric change cost credits?**
No. The preview re-totals scores you already have.

**Q: I changed the rubric. Are old scorecards re-scored?**
No. Scorecards already run keep the version they used. New scorecards use the new one.

**Q: Can I export one part of a file scored in parts?**
Export from the whole file. Its report covers every part.
