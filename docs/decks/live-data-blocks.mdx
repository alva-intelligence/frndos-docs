# Live Data on Slides

A slide can carry a block that stays connected to where its numbers came from. Instead of pasting a screenshot that is wrong a week later, you link the real source and refresh it when you need to.

## Before You Start

1. ✅ **A deck open in the editor** — see [Decks Overview](./overview)
2. ✅ **Something to link to** — connected Insights data, an Audience segment, or a canvas file

## Inserting a Live Object

Open the **Insert** panel with **Insert from frndOS** in the bottom dock, the same item in the deck menu, or **⌘⇧I**.

The panel shows the objects one brand has, as cards:

* **Brand** at the top picks whose objects you see
* Tabs filter by kind: **All**, **Brand IQ**, **Insights**, **Audience**, **Canvas**, **Proposals**
* **Search, or paste any link…** finds an object by name, or inserts whatever link you paste
* The **Insights** section has its own period picker, starting on **Widest with data**

Each card has one action, **Add to slide** or **New slide**, depending on the object. You can also drag a card onto the slide. A card already used in the deck says which slides it's on, and objects with no data yet fold into one line at the end of their section.

## What You Can Put on a Slide

| Linked to | What lands |
|---|---|
| **Chart** | An Insights chart |
| **Block** | A named performance block, listed below |
| **Segment** / **Persona** | Audience data |
| **Canvas** / **Video** | A KV or video file from the creative tools |
| **Artifact** | Campaign work such as **4C**, **Big idea**, **GWTB**, **Campaign plan**, **KPI** or **Verbatims** |

The performance blocks available:

**Latest numbers** · **Top posts** · **Worst posts** · **Spend & pacing** · **Trend** · **Channel mix** · **Campaign scorecard** · **Voice of customer** · **Upcoming posts** · **Campaign timeline**

## The Live Chip

A linked block carries a chip reading its state, what it's linked to, and the period it covers, for example `● Live · Top posts · All time`.

| Chip state | What it means |
|---|---|
| **Live** | Linked and current |
| **Updating…** | Fetching from the source |
| **Source updated · Refresh** | The source moved on; your slide still shows the older pull |
| **Source removed** | What it pointed at is gone |

> **The chip turns amber when it's stale.** That's the signal the slide is showing numbers the source no longer agrees with.

## Editing a Live Object in Place

Select a live object on a slide. The selection bar leads with what it's linked to and its status, for example **Brand IQ · Strategy › Mission** · **In sync**, and an **Edit** button. Click **Edit**, press **Enter**, or double-click the object to open its quick edit beside it. **Open as panel** moves the same editor into the right rail.

What Save changes depends on where the object comes from:

| Linked to | Save changes | The footer says |
|---|---|---|
| **Brand IQ** (a value, the palette, fonts, the logo) | The brand's value in Brand IQ, everywhere it's used | e.g. _"Changes Brand IQ and 3 decks"_ |
| **Insights**, **Audience**, **Canvas** | How it shows on this slide only | _"Changes this slide, not the source"_ |

For an Insights chart you can set the **Period**, **Show as** (**Bars**, **Line** or **Number**), **Title**, **Legend** and **Source line**. A persona or segment lets you choose its **Layout** and which **Fields** show. A canvas file lets you pick a **Version** (**Latest**, or pinned to one) and **Fill** / **Fit**.

> **Approved Brand Books are protected.** If the brand's Brand Book is approved, only a brand admin can change its values from a deck. Others see _"Approved book — admins can edit"_.

On brand text you're allowed to edit, a double-click keeps the cursor in the text so you can type over it. The slide then shows the value as **Edited here**, with **Reset** to follow the source again.

### Used in

The panel lists **Used in**: every deck that shows this piece of brand data, plus the Brand Book pages it's on. The deck you're in reads **This deck**. Decks you can't open are counted, not named. A Brand IQ change updates all of them.

With no other use, it says _"Not used in any deck yet"_. The panel also shows the field's **History** and **Open in Brand IQ**.

### Detaching one element

**Detach here** _"Keeps the value on this slide and stops following the source."_ The object then reads **Detached · Relink**; **Relink** puts the link back and brings in the source's current value.

### Status at a glance

| Status | Meaning | Action |
|---|---|---|
| **In sync** | Matches the source | |
| **Source changed** | The source has moved on | **Refresh** |
| **Source removed** | The source is gone | |
| **Edited here** | Typed over on this slide | **Reset** |
| **Detached** | No longer follows the source | **Relink** |
| **Newer version** | A canvas file has a newer version | **Use latest** |

## Changing the Window

A block covers a period, and you can change it without rebuilding the slide. The options are **Auto**, **7d**, **30d**, **90d**, **This month**, **This year**, **All time** and **Campaign**.

For a block that reads brand data, you can also switch which brand it reads.

## Refreshing, Opening and Detaching

Select the block and the right rail gives you:

| Action | What it does |
|---|---|
| **Refresh** | Pulls current values from the source |
| **Open in Insights** / **Open in Canvas** | Opens the source itself in a new tab |
| **Detach** | _"Keep the elements, drop the link"_ |

**Detach** is how you freeze a slide. The numbers stay exactly as they are and stop tracking the source, which is what you want for a deck that has been signed off and shouldn't move again.

### Your edits survive a refresh

If you've hand-edited values in a linked block, refreshing does not silently overwrite them. The button tells you how many it's keeping, reading **Refresh · N edited kept**, and a tooltip spells out that the edited slots are kept as they are.

> **Heads-up:** that's also the thing to check if a refresh "didn't work". An edited slot is deliberately left alone — use **Reset to source** on that field to hand it back to the source.

## Controlling How It Looks

A linked block isn't locked to one presentation. The right rail carries **Layout**, **Show** (which parts appear), **Title** and **Fit** (**Fill** or **Fit** for images). Turning the title off or rewording it doesn't break the link.

## FAQ

**Q: My slide's numbers are out of date.**
Look at the chip. **Source updated · Refresh** means the source has newer data. Click **Refresh**.

**Q: I want the numbers to stop changing.**
**Detach** the block. The values stay on the slide and no longer follow the source.

**Q: I refreshed and my manual edits are still there.**
That's intended. The button reports how many edited slots it kept. Use **Reset to source** on a field to give it back to the source.

**Q: The chip says Source removed.**
What the block pointed at has been deleted. The slide keeps what it last had; relink it or detach it.

**Q: I changed the brand's tagline in a deck. Did it change elsewhere?**
Yes. Brand IQ values are the brand's own, so the change reaches every deck in **Used in** and the Brand Book. Use **Detach here** first if you want the change on this slide only.

**Q: I changed a chart's period. Did the Insights dashboard change?**
No. Insights, Audience and Canvas objects change on this slide only.

**Q: Can I change the date range without rebuilding the slide?**
Yes. Pick a different period on the block, from **Auto** through to **All time**.
