# Presenting a Deck

A finished deck can be presented from frndOS itself, without exporting it first.

## Before You Start

1. ✅ **A deck with slides** — see [Decks Overview](./overview)
2. ✅ **A keyboard** — presenting is driven by keys rather than on-screen buttons

## Starting

Click **Play** in the top bar. From [Story view](./story-view), **Present** does the same thing.

## Keyboard Control

| Key | What it does |
|---|---|
| **→** or **Space** | Next slide |
| **←** | Previous slide |
| **↓** | Next chapter |
| **↑** | Previous chapter |
| **F** | Fullscreen on or off |
| **Esc** | Leave and go back to the deck |

The same moves are available as on-screen controls, labelled **Previous slide** / **Next slide** and **Previous chapter** / **Next chapter**.

> **Chapters are why ↑ and ↓ exist.** In a long deck, jumping a chapter at a time is much faster than arrowing through every slide. If you wrote the deck in [Story view](./story-view), those chapters are the ones you already defined.

## Fullscreen

**F** toggles fullscreen. If the browser refuses it, presenting still works in the window — some browsers only allow fullscreen immediately after a click, so click the page once and press **F** again.

## FAQ

**Q: How do I get out?**
**Esc** leaves the presentation and returns to the deck.

**Q: Space went forward when I expected it to do nothing.**
**Space** is a second Next, on purpose. It's the key most presenters and remote clickers use.

**Q: Nothing happened when I pressed F.**
The browser blocked the fullscreen request. Click anywhere on the page, then press **F** again. Presenting works windowed either way.

**Q: Can I present a deck someone shared with me as a link?**
A view-only preview link opens the deck for reading. Presenting is done from the editor with **Play**. See [Sharing and Exporting](./overview#sharing-and-exporting).
