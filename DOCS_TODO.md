# Docs TODO Ledger

Every open TODO in `docs/**` — the things only a human can finish (screenshots, third-party/vendor UI steps, flows the code doesn't reveal).

Markers live in each article's **`todo:` frontmatter list**, editable in TinaCMS and never rendered to readers. They must NOT go in the body: a visible marker leaks to readers, and an HTML comment makes Tina fail to parse the whole article (it then opens empty in the editor).

Sections follow the sidebar order (category `position`, then `sidebar_position`).

**Types:** 📸 screenshot · ✍️ confirm from live UI · 🔒 third-party/iframe
